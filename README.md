Playerghost - Настройка прозрачности встроенного плеера.
Современные телевизоры имеют отдельные профили для SDR и HDR / Dolby Vision, при этом профиль переключается автоматически, в зависимости от контента. Профиль для "HDR / Dolby Vision" очень яркий в результате чего белые элементы плеера буквально слепят. Плагин позволяет уменьшить яркость элементов за счёт установки уровня прозрачности.

Torchecker - Автоматическая проверка доступности TorrServer при старте Lampa. Также есть возможность ручной проверки.
Если ваш TorrServer установлен на гаджете с весьма агрессивным контролем фоновых процессов, то иногда TS "засыпает". Данный плагин при старте Lampa выполняет проверку доступности TS (дважды, если с первого раза результат отрицательный). Данный опрос (эхо) доступности "будит" TS, если он "заснул".
